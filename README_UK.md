# Аналіз і візуалізація циклів методом Rainflow

[English version](README.md)

Навчальні реалізації аналізу циклів Rainflow мовою Python. У репозиторії
зібрано останні версії з навчальної папки та додано відтворювані результати.

## Реалізації у репозиторії

| Файл | Призначення |
|---|---|
| `src/task_0.py` | Оригінальний останній скрипт від 15.05.2026; порівнює два режими на детермінованому пилкоподібному сигналі. |
| `src/rainflow_analysis.py` | Підготовлена до публікації версія `task_0.py` з експортом CSV, JSON і PNG. |
| `src/task_5.py` | Важлива геометрична реалізація «потоків дощу» через `process_peaks()` та випадки завершення `b`, `bb`, `c`; містить однорядкове виправлення прихованого звернення до нествореної змінної. |
| `tools/run_task_5.py` | Відтворюваний запуск і збереження результату оригінального `task_5.py`. |

Два режими `task_0`:

- `rainflow_4point` — чотириточковий стековий підрахунок;
- `rainflow_3point_demo` — спрощений навчальний триточковий режим для порівняння.

Триточковий режим і `task_5.py` є навчальними реалізаціями та не заявляються
як сертифіковане еталонне програмне забезпечення ASTM E1049.

## Основні результати

| Реалізація | Точки повороту | Знайдені цикли | Еквівалентні цикли | Вибрані інтервали |
|---|---:|---:|---:|---:|
| Чотириточкова | 404 | 205 | 199,5 | 7 |
| Триточкова навчальна | 404 | 204 | 201,5 | 8 |

Для однакового детермінованого сигналу спрощений режим знаходить на один цикл
менше, але на два еквівалентні цикли більше, бо декілька початкових інтервалів
він класифікує як повні цикли, а не як залишкові півцикли.

## Відтворення результатів

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
python -m pip install -r requirements.txt
python tools/run_all.py
python -m unittest discover -s tests -v
```

Окремий запуск кожного режиму:

```bash
python src/rainflow_analysis.py --method rainflow_4point
python src/rainflow_analysis.py --method rainflow_3point_demo
python tools/run_task_5.py
```

## Перевірка

- обидва режими виконано через єдину відтворювану команду;
- файли JSON, CSV і PNG сформовано повторно;
- три детерміновані модульні тести виконуються успішно;
- оригінальні `task_0.py` і `task_5.py` збережено для простежуваності;
- незмінений варіант `task_5.py` до виправлення збережено як `archive/task_5_original.py`;
- відео, навчальні книги, PDF та особисті файли до репозиторію не включено.
